01 · What we build

More of what people buy is now filtered by software that reads the page on their behalf. It works only from what the page actually states.

ThirdOcular builds instruments for that: written standards for what a category’s buyers need to know, and tests that check a real page against them, requirement by requirement, with the evidence attached.

02 · Products

Two properties, both live. One publishes standards for what a product page has to be able to answer; the other, for what an AI agent has to be able to say about itself.

001 AisleLensLive Buying standards, published and run as tests A buying standard is the set of questions a competent buyer asks in a category, written down, versioned, and executable. AisleLens publishes them, then runs them against a store's real product pages — reporting every requirement as proven, not proven, or requires store access, with the evidence that decided it. Versioned standards, published in full · Run against a store's public product pages · Per-requirement results with the evidence Open AisleLens ↗ 002 PRIVILive Production readiness for agentic systems An AI agent should be able to state what it is allowed to do. PRIVI publishes the checks it has to pass before production, in full, and the tooling that compares what a team says its agent may do against what its code actually does — then says, for each release, which approvals stopped being valid and which still hold.
